# inbox — 問題のタネ置き場

ここに何でも置いて、Claude Code に「inbox を処理して」と言えば、CSVの問題に整形・補完して追加する。
処理が終わったファイルは `done/` に移す。このフォルダの中身（README以外）は git に入らない。

## 置いていいもの（形式は自由）

- 雑なメモ：`吉宗 → 享保の改革　目安箱とか公事方御定書`
- 用語リスト：`江戸の三大改革、田沼、株仲間、天保のききん`
- 「この範囲で20問」などの依頼
- 間違えた問題のメモや、塾テストの写真（※文章は写さず、同じ知識を問う自作の問題にする）
- 「この問題の解説が分かりにくい」「答えが違うかも」などの直し依頼
