# 問題データの書き方

一問一答の問題は分野ごとに3つのCSVで管理する。

| ファイル | 分野 | id |
|---|---|---|
| `questions/history.csv` | 歴史 | `h0001`〜 |
| `questions/geography.csv` | 地理 | `g0001`〜 |
| `questions/civics.csv` | 公民（政治・経済・国際・時事） | `c0001`〜 |

「総合（分野をまたぐ問題）」のファイルは作らない。主な分野のCSVに入れて、タグで横断できるようにする。

`npm run dev` / `npm run build` のたびに自動でチェックされ、まちがいがあれば行番号つきでエラーになる（`npm run questions` で単体チェック）。

## 列

| 列 | 必須 | 書き方 | 例 |
|---|---|---|---|
| id | ○ | 分野の頭文字＋4桁。**一度付けたら変えない**（学習記録のキー） | `h0037` |
| 単元 | ○ | `units.json` にある名前。地理の地域別問題は「〇〇地方」 | `江戸` / `東北地方` |
| 都道府県 |  | 正式名（主に地理） | `青森県` |
| 分類 |  | 問題の種類。アプリで絞り込める | `山` `河川` `湖` `旧国名` |
| 難易度 | ○ | 基本 / 標準 / 発展 / 最難関 | `標準` |
| 学年 |  | 4 / 5 / 6（空欄＝全学年） | `5` |
| 問題 | ○ | 問題文 | `8代将軍徳川吉宗が行った改革を何というか。` |
| 答え | ○ | 正解 | `享保の改革` |
| 別解 |  | ほかに正解とする書き方。`\|` 区切り | `享保改革` |
| 誤答選択肢 |  | 4択用の「まちがいの選択肢」3つ以上。`\|` 区切り。空欄なら4択では出ない | `寛政の改革\|天保の改革\|田沼意次の政治` |
| 解説 | ○ | なぜそうなるか・関連事項 | |
| 漢字注意 |  | 書き間違えやすい点・読み | `「享」を「亨」と書かない。` |
| タグ |  | 横断テーマ。`\|` 区切り | `人物\|漢字` |
| 画像 |  | `public/images/` のファイル名かURL | `/images/uonzu-takamatsu.png` |
| 地図 |  | 緯度,経度（将来の地図機能用） | `34.3428,134.0466` |
| 出典メモ |  | 統計の年・出典。`要確認` で始まると画面に出さない | `作物統計 2024年産` |
| 確認 |  | 保護者が内容を確認したら `済` | `済` |
| 地図問題 |  | 白地図をタップして答える問題にする（下の「地図問題」） | `経線:135` |
| 参考過去問 |  | 入試過去問を参考にした問題の学校・年度。**アプリには出ない**（管理用） | `筑波大附属駒場 2025` |

## 地図問題（白地図をタップする問題）

`地図問題` 列に書くと、日本の白地図をタップ（クリック）して答える問題になる。カード・4択のどちらで出しても地図で出る。タグに `地図タップ` を付けておくと、テーマで選べる。

| 書き方 | 意味 | 正解にする範囲（書かないとき） |
|---|---|---|
| `経線:135` | 東経135度の経線 | ±0.5度（地方の地図は±0.2度） |
| `緯線:40` | 北緯40度の緯線 | ±0.5度（地方の地図は±0.2度） |
| `交点:40,140` | 北緯40度・東経140度の点 | 40km（地方の地図は20km） |

- 範囲を変えるときは後ろに付ける：`経線:140:0.3`（度）、`交点:35,135:30km`
- 地方の地図で出すときは最後に `@地方名`：`緯線:35@近畿`、`経線:140:0.12@関東`。地方名は `content/maps/extents.json` にあるもの（全国 / 北海道 / 東北 / 関東 / 中部 / 近畿 / 中国・四国 / 九州）。書かなければ全国
- 地方の地図は拡大されているので、正解にする範囲は全国より小さい（書かないとき ±0.2度・20km）。地方の地図は当たりやすいので、多くの問題で範囲をさらにせまくする必要がある
- 範囲の2倍までは「おしい」と表示する（記録は×）
- `npm run questions` が「でたらめにタップして当たる確率」を計算し、**10%をこえるとエラー**にする。本州のまん中を通る線などは範囲をせまくする
- 白地図のデータは `content/maps/japan.json`（Natural Earth・パブリックドメイン。作り直すときは `npm run map`）

**タグの例**：白地図 / 人物 / 漢字 / 統計 / 年号 / 多答（すべて答える問題）/ ひっかけ / 郷土富士 / 日本三大 / 比較 / 頻出 / 時事。
タグはアプリの「テーマ」で絞り込める。新しいタグは自由に作ってよい。

**地理の分類**：山 / 山地・山脈 / 河川 / 湖 / 平野・台地 / 盆地 / 半島・岬 / 島 / 湾・海・海峡 / 海岸 / 港 / 特産品 / 工業・伝統工芸 / 旧国名 / 緯度・経度 / 交通 / 名所・文化 / 環境・自然 / その他

## Excelで編集するとき

- 保存は必ず **「CSV UTF-8（コンマ区切り）」**。普通の「CSV」で保存すると文字化けする（チェックでエラーになる）
- セル内改行はしない（解説も1セルに続けて書く）
- 1行＝1問。行の順番は自由

## 単元を増やしたいとき

`units.json` に追記する。並び順がアプリの表示順になる。
