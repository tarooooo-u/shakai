# 問題データの書き方

一問一答の問題は分野ごとに3つのCSVで管理する。

| ファイル | 分野 | id |
|---|---|---|
| `questions/history.csv` | 歴史 | `h0001`〜 |
| `questions/geography.csv` | 地理 | `g0001`〜 |
| `questions/civics.csv` | 公民（政治・経済・国際・時事） | `c0001`〜 |

「総合（分野をまたぐ問題）」のファイルは作らない。主な分野のCSVに入れて、タグで横断できるようにする。

`npm run dev` / `npm run build` のたびに自動でチェックされ、まちがいがあれば行番号つきでエラーになる（`npm run questions` で単体チェック）。

## 列

| 列 | 必須 | 書き方 | 例 |
|---|---|---|---|
| id | ○ | 分野の頭文字＋4桁。**一度付けたら変えない**（学習記録のキー） | `h0037` |
| 単元 | ○ | `units.json` にある名前。地理の地域別問題は「〇〇地方」 | `江戸` / `東北地方` |
| 都道府県 |  | 正式名（主に地理） | `青森県` |
| 分類 |  | 問題の種類。アプリで絞り込める | `山` `河川` `湖` `旧国名` |
| 難易度 | ○ | 基本 / 標準 / 発展 / 最難関 | `標準` |
| 学年 |  | 4 / 5 / 6（空欄＝全学年） | `5` |
| 問題 | ○ | 問題文 | `8代将軍徳川吉宗が行った改革を何というか。` |
| 答え | ○ | 正解 | `享保の改革` |
| 別解 |  | ほかに正解とする書き方。`\|` 区切り | `享保改革` |
| 誤答選択肢 |  | 4択用の「まちがいの選択肢」3つ以上。`\|` 区切り。空欄なら4択では出ない | `寛政の改革\|天保の改革\|田沼意次の政治` |
| 解説 | ○ | なぜそうなるか・関連事項 | |
| 漢字注意 |  | 書き間違えやすい点・読み | `「享」を「亨」と書かない。` |
| タグ |  | 横断テーマ。`\|` 区切り | `人物\|漢字` |
| 画像 |  | `public/images/` のファイル名かURL。`img:名前`（`images.csv` の画像）、`imgs:名前\|名前\|…`（2〜6枚にア・イ・ウ…を付けて並べる。「それぞれ何か」の問題に）、`choices`（答えと誤答選択肢を画像で選ぶ） | `img:雪舟` |
| 地図 |  | 緯度,経度（将来の地図機能用） | `34.3428,134.0466` |
| 出典メモ |  | 統計の年・出典。`要確認` で始まると画面に出さない | `作物統計 2024年産` |
| 確認 |  | 保護者が内容を確認したら `済` | `済` |
| 地図問題 |  | 白地図をタップして答える問題にする（下の「地図問題」） | `経線:135` |
| 出題形式 |  | `4択のみ`：選択肢がないと答えられない問題（「〜はどれか」「正しいものはどれか」「古い順に並べたものはどれか」など）。カードで始めても4択で出る。誤答選択肢3つ以上が必要 | `4択のみ` |
| 参考過去問 |  | 入試過去問を参考にした問題の学校・年度。**アプリには出ない**（管理用） | `筑波大附属駒場 2025` |

## カードと4択

問題はカード（答えを見て自己採点）でも4択でも出る。カードでも答えられるように、ふつうは「〜を何というか」「〜はだれか」の形で聞く。
「〜はどれか」のように選択肢を見ないと答えられない問題は `出題形式` を `4択のみ` にする（`npm run questions` が付け忘れを注意する）。

## 地図問題（白地図をタップする問題）

`地図問題` 列に書くと、日本の白地図をタップ（クリック）して答える問題になる。カード・4択のどちらで出しても地図で出る。タグに `地図タップ` を付けておくと、テーマで選べる。

| 書き方 | 意味 | 正解にする範囲（書かないとき） |
|---|---|---|
| `経線:135` | 東経135度の経線 | ±0.5度（地方の地図は±0.2度） |
| `緯線:40` | 北緯40度の緯線 | ±0.5度（地方の地図は±0.2度） |
| `交点:40,140` | 北緯40度・東経140度の点 | 40km（地方の地図は20km） |

- 範囲を変えるときは後ろに付ける：`経線:140:0.3`（度）、`交点:35,135:30km`
- 地方の地図で出すときは最後に `@地方名`：`緯線:35@近畿`、`経線:140:0.12@関東`。地方名は `content/maps/extents.json` にあるもの（全国 / 北海道 / 東北 / 関東 / 中部 / 近畿 / 中国・四国 / 九州 / 南西諸島）。書かなければ全国
- 地方の地図は拡大されているので、正解にする範囲は全国より小さい（書かないとき ±0.2度・20km）。地方の地図は当たりやすいので、多くの問題で範囲をさらにせまくする必要がある
- 範囲の2倍までは「おしい」と表示する（記録は×）
- `npm run questions` が「でたらめにタップして当たる確率」を計算し、**10%をこえるとエラー**にする。本州のまん中を通る線などは範囲をせまくする
- 白地図のデータは `content/maps/japan.json`（Natural Earth・パブリックドメイン。作り直すときは `npm run map`）

**タグの例**：白地図 / 人物 / 漢字 / 統計 / 年号 / 多答（すべて答える問題）/ ひっかけ / 郷土富士 / 日本三大 / 比較 / 頻出 / 時事。
タグはアプリの「テーマ」で絞り込める。新しいタグは自由に作ってよい。

**地理の分類**：山 / 山地・山脈 / 河川 / 湖 / 平野・台地 / 盆地 / 半島・岬 / 島 / 湾・海・海峡 / 海岸 / 港 / 特産品 / 工業・伝統工芸 / 旧国名 / 緯度・経度 / 交通 / 名所・文化 / 環境・自然 / その他

## 白地図ドリル（1枚の地図にいくつも印を付ける問題）

ふだんの問題（`questions/*.csv`）とは別に、サイドバーの「白地図ドリル」から解く。ふだんの出題には出ない。

- `maps/places.csv`：地名。列は `id`（`p0001`〜。**変えない**）・`名前`・`読み`・`種類`（山地・山脈 / 火山 / 山 / 岬 / 河川 / 平野 / 台地 / 干拓地 / 盆地 / 湖 / 半島 / 島 / 港）・`座標`・`解説`・`漢字注意`・`出典メモ`・`確認`
  - `座標` は「北緯,東経」。1点なら▲（岬は●、港は■。火山でない山も▲）、`;` で区切って2点以上なら線（山脈・川）：`43.10,142.75;42.60,142.85;42.05,143.15`
  - 種類が `平野`・`台地`・`干拓地`・`盆地`・`湖`・`半島`・`島` のときは、まわりを3点以上でぐるっと囲んだ面になる（平野は海にはみ出さないように）。地図の上で小さい面には、目印の丸が付く
  - いくつかに分かれた面（対馬・隠岐諸島・五島列島など）は、輪郭ごとに「/」で区切る：`34.5,129.3;…;34.4,129.4 / 34.2,129.2;…`
  - 島・半島の輪郭は白地図（`japan.json`）の海岸線から作った（島はその島の輪郭、半島は付け根の2点の間の海岸線）
  - 山脈・川の線は模式的でよい（山脈は2〜4点、川は水源・通る町・河口の5〜9点）。川の河口は海岸に合わせる。ほかの印と見分けられるか、地図で確認する
  - 川は上流が地図の外に出てもよい（3点以上が地図の中にあれば OK）
- `maps/sets.csv`：地図。列は `id`（`m01`〜）・`名前`・`地図`（`extents.json` の名前）・`地名`（`|` 区切り）
  - 地図は「全国＋7地方」と南西諸島（奄美・沖縄。全国の地図に入らないため）。地方の地図には、その地方の地名を種類を問わず全部入れる。全国の地図には入試によく出るものだけ
  - アプリでは「しぼる」で種類のまとまり（山・火山 / 川・湖 / 平野・盆地（台地・干拓地も） / 半島・島・岬 / 港。`lib/mapSets.ts` の `KIND_GROUPS`）にしぼれる。全国の地図は種類ごと（山地・山脈だけ、火山だけ…）に出す
  - 1つの地図で、いっしょに出す印（地方はまとまりごと、全国は種類ごと）は16個まで
  - 同じ地名を全国と地方の両方に入れてよい（学習記録は地名ごとに1つ）
- 面（平野・盆地・湖）と川・山はかさなってよい（平野の中を川が流れる）。面どうしはくっついていなければよい。印をえらぶときは線・点が平野より先にえらばれ、面の中に面があれば小さいほう。線・点のそばでは点（山脈の上の山）。場所をタップでは、同じまとまりで同じ形（点・線・面）の地名どうしだけをくらべる（平野と川、半島と湖、山脈と山はくらべない）。点どうしは、まとまりがちがってもかさならないようにする（地方の地図）
- 答え方は「地図でえらぶ」（名前→印）・「名前を答える」（印→名前。4択かカード）・「場所をタップ」（印のない地図にピンを立てる）。記録と卒業は答え方ごと
- 場所をタップの正解の範囲：地方の地図は `extents.json` の `tolKm`（20km）、全国・北海道のような広い地図は地図の上で最低36（横はば800のとき）。山脈・川の線はその0.7倍の帯、平野・盆地・湖は中ならどこでも正解で、まわりに0.5倍の帯。ほかの地名の範囲に入ったら×
- `npm run questions` が、地図の範囲からのはみ出し、印が近すぎて見分けにくいところ（同じまとまりの中で）、場所をタップで勘で当たる確率が16%をこえる地名を注意する

## データシート（赤シートのように、かくした所をタップでめくる）

表・グラフ・組織図の一部を赤い紙でかくし、思い出してからタップでめくる。サイドバーの「データ」から開く。ふだんの出題には出ない。

- 1枚＝`sheets/*.json` 1ファイル。`npm run questions` がチェックして `data/sheets.generated.json` を作る
- 共通の項目：`id`（英小文字・数字・`-`。**変えない**。学習記録のキー）・`title`・`category`（history / geography / civics）・`unit`（`units.json` の単元）・`kind`・`modes`・`note`（グラフの見方など。画面に出る）・`source`（出典。画面に出る）・`sourceNote`（作り方のメモ。画面に出ない）
- `modes` はかくし方。`{ "id": "name", "label": "名前をかくす", "hide": ["name"] }` のように、かくす文字の種類を `hide` に書く
- `kind` は3つ
  - `tree`（組織図）：`root` から `children` でつなぐ。箱は `name`（名前）と `desc`（説明）。`label` だけの箱は「中央」「地方」などのまとまり（`tone`：amber / green / gray / blue で色）。まとまりの中の箱の子は下に出る。かくせる種類：`name` / `desc`。名前はシートの中で重ならないようにする（記録のキー）
  - `cards`（国ごとの順位表など）：`columns`（3つ）と `cards`（`title`・`sub`・`rows: [{label, value}]`）。かくせる種類：`title` / `label` / `value`。左には「1位」「2位」…が出る。同じ順位や「北海道」「長い川」など順位でない見出しにしたい行は `head` に書く（かくさない）
  - `bars`（割合の帯グラフ）：`series`（項目名）と `rows`（`label` と `values`。割合はアプリが計算する）。4%より細い所は数字を書かない。かくせる種類：`series` / `value` / `row`
- タップでめくる → もう一度タップで ×（もう一度で × を消す）。× はかくし方ごとに保存し、「×だけかくす」で復習できる
- 統計の数字は塾の資料から写さず、元の統計から取る
  - `imports-by-country.json`（主な貿易相手国からの輸入品）：`npm run trade` で e-Stat の貿易統計から作る（`scripts/update-trade.mjs`）。新しい年は表ID・年を差し替えて再実行
  - `electricity-mix.json`（発電量の割合）：資源エネルギー庁のExcel（自動では取れない）から手で書き写した値（億kWh）。新しい年度は総合エネルギー統計の時系列表「4.電源構成(発電量)」から足す

## Excelで編集するとき

- 保存は必ず **「CSV UTF-8（コンマ区切り）」**。普通の「CSV」で保存すると文字化けする（チェックでエラーになる）
- セル内改行はしない（解説も1セルに続けて書く）
- 1行＝1問。行の順番は自由

## 単元を増やしたいとき

`units.json` に追記する。並び順がアプリの表示順になる。
