# 入試過去問から問題を増やす手順

保護者が過去問の PDF（スキャン）を渡して「問題を増やして」と頼んだときの手順。学校名は問わない。
過去問は**問題をつくるための参考資料**として読む。アプリに入れるのは、自作した文章の問題だけ。

## 線引き（いちばん大事）

**知識と考え方は取り出す。題材の組み合わせと問いの形は持ち込まない。**

| 取り出してよいもの | アプリでの問題の形 |
|---|---|
| 知識（用語・人物・年号・統計の論点）。SAPIX より一段細かいものも | 一問一答（難易度は「発展」「最難関」が中心） |
| 因果・理由（なぜその場所で、なぜその時期に） | 「〜の理由として最も適切なものはどれか」答え＝理由、誤答＝もっともらしいが違う理由 |
| 正誤のひっかけ方（時期のずれ、主語の入れかえ、言い過ぎ、似た制度の混同） | 自作の文で「正しいもの／正しくないものはどれか」 |
| 統計・グラフで問われる見方 | 同じ見方を、**別の年の最新データ**（公式統計）で問う |
| 分野をまたぐつながり、時期の比べ方 | タグ `比較` `ひっかけ` `理由` `年号` などで横断 |
| 記述問題の論点 | 4択の「理由選び」「説明として正しいもの選び」に作りかえる |

持ち込まないもの：

- 大問の**題材・リード文の筋書き**（例：ある施設の100年史で大問を組み立てる）
- **同じ事実の組み合わせ**でできた選択肢セット。1問の中の4択は、元の問題とはちがう事実で作る
- 試験の**表・グラフ・地図・地形図とその数値**
- 問題文・選択肢の**言い回し**
- その学校の地元の細かい題材（その年の入試だと分かってしまうもの）
- 「東京か大阪か分類して時代順」のような、**独特な問いの形式**そのもの

目安：**1問ずつ見ても、全体を見ても、特定の学校・年度の入試とは対応しない**こと。

出典メモに学校名・年度は書かない。どこから取ったかは `private/過去問取り込み記録.csv` だけに残す。

## 手順

### 1. PDF の構成をつかむ

```bash
pip install pymupdf
python scripts/pdf-pages.py "<PDF>" "<作業用フォルダ>" --sheets
```

- 作業用フォルダは**リポジトリの外**（Claude の scratchpad など）。PDF もページ画像もリポジトリに置かない
- 一覧画像（20ページずつ）を見て、年度ごとの「問題ページ」「解答用紙」「解答」の位置を確かめる
- スキャンが上下さかさまのページがある（筑駒 2024 など）。一覧画像で文字がさかさまなら `--rotate 180`

### 2. 1年分を高解像度で読む

```bash
python scripts/pdf-pages.py "<PDF>" "<作業用フォルダ>" --pages 142-150 --rotate 180
```

- 1ページを上下半分ずつ読む（`p142_0.png` が上半分、`p142_1.png` が下半分）。ふりがなまで読める
- 解答ページも読み、正解を確かめる（正誤問題の「どれが誤りか」は、ひっかけの型を知る手がかりになる）

### 3. 論点を書き出し、既存の問題と照らし合わせる

- 小問ごとに、問われている知識と、各選択肢の正誤の根拠を書き出す
- `content/questions/*.csv` を grep し、すでにある知識は「別の角度（理由・比較・ひっかけ）で足せるか」だけを考える。同じ問いは追加しない
- まだ手薄な分野を優先する（今までに足したのは、地形図の縮尺、資源・エネルギー、地方自治、林業など）

### 4. 問題をつくる

- 書式・単元・タグは `content/README.md` と `content/units.json` にしたがう。CLAUDE.md の「問題を追加・修正するとき」のルール（自作の文、事実の確認、`要確認`、誤答は同じ種類でまぎらわしいもの、id の振り方、`確認` 列は空欄）もそのまま守る
- 1年分で 30〜40問 が目安
- 時事は「何年時点か」を解説か出典メモに書く。統計で自信のない数字は、出典メモを `要確認：…` で始める（アプリには出ない）
- CSV への追記は、Python の `csv` モジュールで `quoting=QUOTE_ALL`・`lineterminator="\r\n"`・UTF-8 で行う
  - 追記前に改行コードを確認する（LF のファイルに CRLF の行を足すと、チェックで「Invalid Closing Quote」になる）

### 5. チェックと記録

1. `npm run questions` を通す
2. `private/過去問取り込み記録.csv` に追記する（列：学校・年度・取り込み日・論点・扱い・問題ID）。扱いは「新規追加」「既存（別の角度で追加）」など
3. 作業用のページ画像を削除する
4. 保護者に報告する：
   - どこまで踏み込んだか、わざと入れなかったもの
   - 追加した問題の一覧（id・答え）
   - 要確認の点

## 進み具合を聞かれたら

`private/過去問取り込み記録.csv` を学校・年度ごとに集計して答える。

```bash
python -c "import csv,collections;r=list(csv.DictReader(open('private/過去問取り込み記録.csv',encoding='utf-8-sig')));c=collections.Counter((x['学校'],x['年度']) for x in r);[print(k,v) for k,v in sorted(c.items())]"
```
